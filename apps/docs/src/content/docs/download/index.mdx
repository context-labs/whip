## Command line

Install the standalone CLI on macOS or Linux. The installer selects your platform and verifies the download checksum.

<CodeTabs label="CLI installation">
<CodeTab label="Install">

```bash
curl -fsSL https://raw.githubusercontent.com/context-labs/whip/main/install.sh | sh
```

</CodeTab>
<CodeTab label="Inspect first">

```bash
curl -fsSL https://raw.githubusercontent.com/context-labs/whip/main/install.sh -o install-whipcode.sh
less install-whipcode.sh
WHIPCODE_CHANNEL=prerelease sh install-whipcode.sh
```

</CodeTab>
</CodeTabs>

Requires `curl`, Python 3, and `sha256sum` or `shasum`. No Node.js or Go installation is needed to run the packaged CLI.

The default location is `~/.local/bin/whipcode`. Add `~/.local/bin` to your `PATH` if needed, then verify the installation:

```bash
whipcode --version
```

Continue with the [Quickstart](/docs/quickstart).

## Updates and release channels

Whip is currently a prerelease. Keep `WHIPCODE_CHANNEL=prerelease` in the installer command; the stable channel does not fall back to prereleases.

- **Desktop:** get a newer app from [Releases](https://github.com/context-labs/whip/releases). Use Desktop's **Upgrade** action for a Desktop-managed backend.
- **Standalone CLI:** run `whipcode update`. An alpha installation follows the prerelease channel. Updating also requests a restart of that installation's daemon.

Finish active work before upgrading. Do not update a Desktop-managed backend independently with the CLI.
