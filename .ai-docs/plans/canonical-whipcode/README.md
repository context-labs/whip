## Use and future updates

Open Whip normally, run `whipcode`, or visit `http://127.0.0.1:8080`.
`whipcode daemon status --json` reports the shared daemon. Closing desktop leaves
the daemon running; `whipcode daemon stop` stops it explicitly.

No setup action is currently required. Provider access uses the environment:
if that credential is removed later, run `whipcode auth inference-net login` or
configure a provider in Settings. Fresh computer-use permissions are requested
through normal macOS prompts when those features are used.

This installation follows source builds, with its release update feed disabled.
For an update, build/sign/verify a new payload from this checkout, quit clients,
stop the canonical daemon, atomically replace its binary and the desktop app,
then start and verify. Do not replace the backend while workers are running or
install another copy through an unqualified `go install`/release updater.
