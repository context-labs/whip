# Frontend work

For changes to `apps/web`, `packages/app`, `packages/ui`, or the frontend-facing
parts of `packages/sdk` and `packages/protocol`, read
[docs/frontend.md](docs/frontend.md) first. It is the canonical guide to package
boundaries, design philosophy, state ownership, data fetching, styling, theming,
and validation. Follow its source links for the area being changed.

Keep that guide current when changing a frontend architectural decision.
Historical `.ai-docs/plans` documents record research and prior proposals; they
are not a second source of current implementation requirements.
