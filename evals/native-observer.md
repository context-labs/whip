# Native evaluation observer

New trials use native-v4 and the separate
`frontier-v1-native-v4-local-v1/kimi-k3-fast-inference-high` baseline track.
They cannot promote over the old execution contract. Engine selection is frozen
in the protocol unless explicitly selected; no personal or retired config is read.
The observer constructs private native host configuration, captures exact catalog
prices, creates one real tree through native RPC and grants only the disposable
workspace operations needed by the fixture. Descendants receive native delegated
authority. The observer never writes runtime SQLite state.

Finality requires CLI exit, no runnable tree work and two seconds without database
commits. All active turns, unclaimed inputs, operations, permissions, model attempts,
armed goals and runnable mail block finality. Failed latest prompt turns block
mail at every depth; future schedules and next-turn mail remain in the copied
database without preventing finality. Freeze verifies public runtime identity,
private held lock, executable, arguments, home, lock descriptor and process start
time before pidfd signaling or the checked fallback. A stopped process resumes only
through the captured identity. The frozen snapshot must match the last settled read.

Attempt ancestry accounts for deleted descendants. Integer nanodollars are the
accounting authority; absent usage, cache usage or cost stays unknown. The copied
database is checked against state.json during report normalization. Content export
joins exact tree owners and copies each bounded immutable object once, verifying
size and SHA-256 without following substituted symlinks. Full messages, canonical
trace rows and future schedules live in the database backup, not duplicate event
or transcript arrays. Retired span counters are unavailable for native evidence;
they are not inferred from the differently defined native trace index.

## Validation and retained scenarios

`sh evals/check-native.sh` runs canonical and retained offline regressions. On Linux
it also builds the actual CLI and runs both engines against the loopback provider
in fresh private homes. The provider waits for genuine child work, exercises file
reads/writes and scoped large content, and never contacts an external model.
The test then verifies copied evidence, report normalization, edited-accounting
rejection, queued-child-input finality and substituted-body rejection.

| Retained behavior | Native coverage or explicit replacement |
| --- | --- |
| Root CLI completion before child | Both-engine actual runtime acceptance checks root/child finish order and completion mail |
| Whole-tree usage and cost; unknown is not zero | Native attempt tests, exact >2^53 nanodollars, actual Harbor/Pier AgentContexts |
| Root/child transcript identity | Native owner identity in snapshots; full canonical messages remain in database backup |
| Event changes restart quiet window | PRAGMA data_version; every database commit resets quiet time; read failure cannot reuse settled state |
| Retry barrier, queued input, operations, permission, schedules | Retained finality tests ported to native columns; barrier tested at root and child, armed goals/attempts included |
| PID reuse/home/executable/Rosetta protection | Private held native runtime lock plus public status; fallback negative identity tests and real Linux pidfd freeze |
| Exact owned content, missing/mismatched bodies, symlink refusal | Ported retained export tests plus real scoped object export |
| Intermediate cat polling/download timeout | Removed earlier by mounted-evidence adapter; test proves no cat or download occurs, only final files count |
| Lost exec, nonzero exit, missing/corrupt evidence, cancellation | Native mounted-evidence tests keep unknown accounting and exact-home shutdown |
| Stalled daemon cleanup | Bounded cleanup preserves primary observer error and unknown accounting |
| Watchdog ownership, task timing, paired schedule | Retained study tests; current setup budget and native recipe fields are explicit |
| Archived v2 reports/integrity | Read-only historical aggregate and original result/integrity readers; original reports and hashes unchanged |

runs in an offline disposable container, six tests in13.232s, including native

are not full Harbor/Pier runner qualification and are not performance or model
proficiency evidence. Full doctor qualification is being run separately. Its first
